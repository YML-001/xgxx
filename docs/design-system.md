# 学工信箱 — 设计系统（对齐学工系统规范）

> 本板块样式已对齐《学工 PC 端 · 前端设计规范》与《学工移动端 · 前端设计规范》。  
> 原型为纯前端 HTML/CSS/JS，视觉令牌与学工现网一致；内容与交互不变。

---

## 1. 视觉气质（一句话）

**淡蓝底（`#E3F1F9`）+ 白色圆角卡 + 蓝色系主色 + 深墨蓝文字（`#1E323F`）**，状态用绿/橙/红/灰四色 chip。

---

## 2. PC 端令牌（对齐学工 PC）

| 令牌 | 值 | 用途 |
|------|-----|------|
| 主色 | `#2A8DC7` | 按钮描边/文字、链接、表头字 |
| 辅主色 | `#3087CC` | 页面级提交按钮 |
| Tab 激活 | `#006DAD` | Tags 激活文字与下边线 |
| 侧栏底 | `#458FD8` | aside |
| 内容区底 | `#E3F1F9` | layout-main |
| 白卡 | `#FFFFFF` / `radius: 8px` | **无阴影** |
| 表头底/字 | `#D6EAF9` / `#2A8DC7` | 表格 |
| 表单边框 | `#C7E1F0` | input/select/textarea |
| 标题文字 | `#1E323F` | SectionTitle / KPI |
| 卡片标题 | `#3C444F` | 弹窗/卡片标题 |
| 次级文字 | `#627079` | 说明、meta |
| 弹窗圆角 | `12px` | dialog |
| 弹窗阴影 | `0 10px 20px 10px rgba(0,0,0,.05)` | dialog |

状态标签（zt_tag 风格）：
- 进行中：`#2A8DC7` / `#D6EAF9`
- 成功：`#1BB975` / `#E8FCF4`
- 警告：`#F29100` / `#FFF5E5`
- 危险：`#DF2027` / `#FCE8EA`
- 中性：`#C8CAD1` / `#F1F2F3`

---

## 3. 移动端令牌（对齐学工移动）

| 令牌 | 值 | 用途 |
|------|-----|------|
| 页面底 | `#E3F1F9` | 业务页标准底色 |
| 主按钮渐变 | `linear-gradient(102deg, #469FFF → #065CF8)` | 提交/确定 |
| 卡片 | `radius: 16px` + `0 4px 16px rgba(30,50,63,.04)` | 列表卡 |
| 正文 | `#1E323F` / 14px | 标题与正文 |
| 次级 | `#627079` | 元信息 |
| 弱化 | `#979FA6` | 空态、取消 |
| 表单边框 | `#BAD8EA` | 输入框 |
| 占位符 | `#8CBCD9` | placeholder |
| FAB | `linear-gradient(180deg, #3087CC → #006DAD)` | 悬浮按钮 |

状态 chip（st-*）：
- 成功 `#1EC997` / `#E8FCF4`
- 警告 `#FF9800` / `#FFF5E5`
- 危险 `#F43F51` / `#FCE8EA`
- 结束 `#627079` / `#EEEEEE`

---

## 4. 文件位置

| 文件 | 说明 |
|------|------|
| `css/style.css` | PC 端样式（令牌 + 组件） |
| `css/mobile.css` | 移动端样式 |
| `pages/assets/css/*` | 由 `node tools/build-pages.js` 同步的自包含副本 |

修改源 CSS 后请执行：

```bash
node tools/build-pages.js
```

---

## 5. 与现网差异说明（原型边界）

- 原型未接入 Element Plus / VXE / uView，仅对齐**视觉令牌与组件观感**。
- 未改业务逻辑、文案、数据结构与页面信息架构。
- 侧栏/顶栏为原型自有壳层，色值已按规范 aside/header 对齐。
